My Projects

Robotic Manipulator for the Food Industry

This project focused on designing a robotic arm that could gently handle produce without damage. Controlled through a glove that tracked hand motion, the arm used soft gripping materials, motion control in Python, and FEA analysis to ensure both precision and safety. It was created to explore practical automation solutions in agriculture and food packaging.

Drilling Jig & Inspection Gage Design

This manufacturing-focused project involved designing a custom jig to hold cylindrical parts in place during drilling, alongside an inspection tool to verify machining accuracy. The fixture followed the 3-2-1 constraint method, while the GO/NO-GO gage used GD&T principles to ensure quality. Every component was modeled in SolidWorks and based on real-world suppliers.

Automated Bearing Installation System

This project involved automating a pneumatic system to install motor bearings with speed and precision. Using an Allen-Bradley PLC, the control logic managed timing, sequencing, and safety. The system was designed with both reliability and workplace safety in mind, following OHSA-compliant planning.

Inverted Pendulum Stabilization System

A hands-on control systems project where the goal was to balance an inverted pendulum using feedback and real-time corrections. A PID controller was tuned and simulated in Python, then tested with sensors and actuators. It was a practical challenge that brought dynamic system theory to life.
